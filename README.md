This project aims to predict Air Quality Index (AQI) using Machine Learning algorithms such as Random Forest and Artificial Neural Networks (ANN). The model is trained on environmental sensor data including pollutants like CO, NO2, SO2, and PM2.5.

The system performs data preprocessing, feature selection, and model training to accurately forecast AQI levels. Visualization techniques are used to represent pollution trends and patterns.

This project can be useful for:
- Smart city applications
- Environmental monitoring
- Health risk analysis
- Real-time pollution tracking systems

Technologies Used:
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib / Seaborn
